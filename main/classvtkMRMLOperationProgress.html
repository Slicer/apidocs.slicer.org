Detailed Description

Progress of a long operation, such as loading files.

The object that performs the operation passes this object as call data of the events that report the start, progress, and end of the operation (for example, vtkMRMLFileIOManager::OperationStartEvent, OperationProgressEvent, and OperationEndEvent). Observers can get the progress and text to display and can request aborting of the operation.

The same object is used for all events of an operation. Work that is done while an operation is in progress (for example, loading each file of a list) is part of that operation. The overall progress never decreases. ProgressEvent is invoked when the progress, the progress text, or the current file changes. The object contains a full state, which is useful if progress update events are skipped because of limits on maximum rate of progress updates. The latest state is always reported before EndEvent.

In Python, the observer must specify that the call data is a VTK object:

@vtk.calldata_type(vtk.VTK_OBJECT)
def onProgress(caller, event, progress):
if progress.GetNumberOfFiles() == 0:
print(f"In progress: {progress.GetProgressText()}") # the total amount of work is unknown
else:
print(f"{progress.GetProgress() * 100:.0f}% {progress.GetProgressText()}")
fileIOManager = slicer.app.applicationLogic().GetFileIOManager()
fileIOManager.AddObserver(fileIOManager.OperationProgressEvent, onProgress)

◆ GetNumberOfFiles()

virtual int vtkMRMLOperationProgress::GetNumberOfFiles ( )
virtual

Number of files that the operation processes (for example, number of files to load or nodes to export). 0 means that the total amount of work is unknown (progress cannot be estimated, for example a busy indicator can be displayed). The number of files may change while the operation is in progress (for example, from 0 to 1 when it turns out that progress of loading the file is reported).

◆ GetProgress()

Overall progress of the operation, in the range of 0.0-1.0. It is only meaningful if the number of files is not zero.

◆ GetProgressRangeMinimum()

virtual double vtkMRMLOperationProgress::GetProgressRangeMinimum ( )

For internal use by the operation that reports the progress. Observers must not modify these values. Part of the overall progress range that the currently processed item covers. It is smaller than the range of the current file if lists are nested (for example, if loading a file loads a list of other files).

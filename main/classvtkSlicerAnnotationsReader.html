Detailed Description

Reader of legacy annotation files (.acsv).

Properties: "fileName", "name", "annotationType" ("fiducial", "ruler", or "roi"). For backward compatibility, the annotation type can be specified by "fiducial", "ruler", "roi" boolean properties.

Detailed Description

Writer of the MRML scene to a .mrml file, a Medical Reality Bundle (.mrb) file, or a Slicer Data Bundle (directory).

Properties: "fileName", "screenShot" (vtkImageData, optional).

Write the node named by the "nodeID" property to the file named by "fileName". What it wrote is then in GetWrittenNodeIDs. The base class writes nothing: a writer whose work is done elsewhere is called through its owner.

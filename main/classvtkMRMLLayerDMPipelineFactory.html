vtkMRMLNode * node,
vtkSmartPointer< vtkMRMLLayerDMPipelineCreator > * creator )

Tries to create a new pipeline given input viewNode and node by iterating on its creators. Returns nullptr if no creator was able to create a pipeline. If creator is not nullptr, it is set to the creator that created the pipeline. Invokes PipelineAboutToBeCreatedEvent before returning the newly created pipeline instance.

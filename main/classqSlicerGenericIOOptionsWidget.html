Detailed Description

Options widget that displays the options of a VTK-based reader or writer (see vtkMRMLIOOptionsDescription).

See https://slicer.readthedocs.io/en/latest/developer_guide/mrml_overview.html#reader-and-writer-options

◆ onApplicationAboutToQuit

void qSlicerGenericIOOptionsWidget::onApplicationAboutToQuit ( )
protectedslot

Called when the application is about to quit. Node selectors stop observing the scene, because nodes may be removed from the scene after the application object is deleted (if this widget still exists at that time, for example because it was created from Python without a parent), and node selectors must not update their GUI then.

Detailed Description

Registered MRML node classes of a scene.

Stores a prototype instance of each registered node class, used for creating nodes by class name or XML tag.

It can be shared between scenes (see vtkMRMLScene::SetNodeFactory()), to allow creating scenes without instantiating a prototype of all the node classes. This is useful when a large number of scene nodes need to be created, for example for storing scene views.

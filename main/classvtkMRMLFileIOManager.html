Detailed Description

Manages reading and writing of files: keeps the list of registered readers and writers, chooses the reader or writer to use for a file or a node, and loads and saves nodes using them. The application logic owns the file IO manager of the application (vtkMRMLApplicationLogic::GetFileIOManager()).

See https://slicer.readthedocs.io/en/latest/developer_guide/mrml_overview.html#file-reading-and-writing

◆ ExamineFileList()

vtkMRMLFileReader * vtkMRMLFileIOManager::ExamineFileList ( std::vector< std::string > & fileList,
vtkMRMLIOProperties * ioProperties )

Iterates through readers looking at the file list to see if there is an entry that can serve as an archetype for loading multiple files. If so, the reader removes the recognized files from the list and sets the ioProperties so that the corresponding loader will read these files. The "fileName" property is set to the archetype file. Returns the reader that recognized the files or nullptr if no pattern is recognized. If multiple readers recognize a group of files then the one with the highest confidence (see vtkMRMLFileReader::ExamineFileListConfidence) is used. The specific motivating use case is when the file list contains a set of related files, such as a list of image files that are recognized as a volume. In Python, fileList must be a list (it is modified in place).

Export a single node to a file. Used by ExportNodes() to export each node of the list.

The node is copied into temporaryScene (with its display node and, if requested, with its parent transforms hardened) and saved from there, so that the storage nodes of the main scene are not modified.

Parameters
propertiesExport options: "nodeID" (ID of the node in the main scene), "fileName", "fileFormat", and any other options that the writer uses.
temporarySceneScene that ExportNodes() created for exporting. It is shared by all nodes of the list.
hardenTransformsIf true, parent transforms of the node are applied to the exported data.
userMessagesErrors and warnings to display to the user are added to this collection (may be nullptr).
Returns
True if the node was exported successfully. False if any error occurred, for example: the "nodeID", "fileName", or "fileFormat" property is missing, no storable node exists with the specified "nodeID", the node cannot be copied into the temporary scene, or the writer fails to write the file.

◆ ExportNodes() [2/2]

bool vtkMRMLFileIOManager::ExportNodes ( vtkCollection * propertiesList,
bool hardenTransforms,
vtkMRMLMessageCollection * userMessages = nullptr )

Export nodes using the registered writers. Unlike SaveNodes(), this function creates a temporary scene while saving, in order to avoid modifying storage nodes in the current scene. Saving progress is reported (see SaveNodes()), each exported node counts as one file. Exporting of multiple nodes is abortable. Each item in propertiesList is a vtkMRMLIOProperties object that specifies a "nodeID" (ID of a node in the main scene), a "fileName" (an absolute file path), a "fileFormat" (e.g. "NRRD (.nrrd)"), and any other options that the associated writer may use. If hardenTransforms is true then transforms are temporarily hardened before export. If a node cannot be exported then the remaining nodes are still exported. Returns true if all nodes were exported successfully.

vtkMRMLFileWriter * vtkMRMLFileIOManager::GetWriterForObject ( vtkObject * object,
const std::string & format = std::string() )

Return the best file writer for this object. Best match is the writer that supports the node type and the specific format (name filter, such as "NRRD (.nrrd)"), closest match is the writer that supports the node type but not that specific format. If there are multiple matches then the one with the highest confidence is returned. If format is empty then the writer with the highest confidence is returned.

Loading.

Load nodes using the readers of the file type. The properties must contain "fileName" (a string or a list of strings) and may contain more specific properties. For example, the volume reader can be called with the following parameters: "labelmap" (bool), "center" (bool). Nodes that are loaded are added to loadedNodes (if not nullptr). If a valid userMessages is passed then additional error or warning information is added to it. Returns false if loading fails.

Progress is reported by OperationStartEvent, OperationProgressEvent, and OperationEndEvent. A list of files is loaded as one operation, which can be aborted between files.

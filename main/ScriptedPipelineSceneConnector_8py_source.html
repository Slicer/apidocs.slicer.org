8class ScriptedPipelineSceneConnector:
9 """
10 Convenience base class connecting the scripted LayerDM pipelines of one module to the scene.
11
12 Subclass and override:
13 - getPipelines: return the pipeline classes handled by the module.
14 - getSceneObservers: optionally return (eventId, callback) pairs to observe on the MRML scene.
15 - onConnected: optionally perform additional setup after connecting (for instance adding
16 data nodes to the scene).
17
18 Expected usage in a scripted module:
19 - Instantiate the subclass at module level.
20 - Call connect at application startup and from the module widget's setup. connect removes any
21 previous connection first, so re-connecting from setup makes a module reload rebind the
22 reloaded pipeline classes (the LayerDM pipeline managers automatically recreate the pipelines
23 of a creator which was removed from the factory).
24 - Call disconnect from the module widget's cleanup, which is invoked by the module reload
25 machinery before the widget is rebuilt and when the module is unloaded.
26 """

Detailed Description

Reader of sequence files.

Properties: "fileName", "name", "show" (create a sequence browser and show the proxy node), "colorNodeID".

If a sequence browser node is created then ShowSequenceBrowserRequestedEvent is invoked, with the sequence browser node as call data, so that the application can show the sequence browser toolbar.
